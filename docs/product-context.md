# AI 销售平台产品认知说明

本文档是 AI 销售平台的统一产品认知源，用于后续官网项目、交付文档、培训演示、销售材料和需求讨论。后续新建官网项目时，应优先复制或引用本文档，保证对产品定位和业务逻辑的理解一致。

## 1. 产品定位

AI 销售平台是一套面向企业私域销售场景的企微 AI 销售托管平台。

它不是单纯的聊天机器人，也不是传统客服系统，而是围绕企业微信账号、客户会话、智能体角色、销售生命周期、Skill/SOP 任务、工具调用和第三方业务系统构建的一套 AI 销售运营平台。

核心定位：

> 帮助企业把私域客户跟进流程标准化、自动化、可追踪，让 AI 按配置好的销售流程主动跟进客户，并支持运营人员随时查看、干预和复盘。

## 2. 目标客户

优先适合以下类型企业：

- 教育培训机构
- 咨询服务公司
- 本地生活服务商
- 企业服务销售团队
- 私域成交依赖较强的公司
- 客户跟进流程复杂、销售人员执行不稳定的团队
- 有企微客户池，但缺少标准化跟进和过程监控的团队

典型客户特征：

- 使用企业微信承接线索和客户沟通。
- 销售跟进依赖人工经验，过程不可控。
- 客户生命周期较长，需要多次触达。
- 客户信息、订单、标签分散在多个系统。
- 管理层希望看到 AI 参与订单、客户阶段、人工介入和任务执行情况。

## 3. 核心价值

平台核心价值可以概括为：

1. **销售流程标准化**
   - 把销售 SOP 拆成生命周期阶段和 Skill。
   - 不同阶段配置不同目标、话术、任务和工具。

2. **客户跟进自动化**
   - AI 根据客户阶段、会话内容、客户资料自动回复。
   - 支持定时任务、阶段推进和自动触达。

3. **企微账号托管**
   - 将企业微信账号绑定智能体。
   - 支持 AI 托管、人工接管、消息发送开关。

4. **第三方系统打通**
   - 支持用户画像查询、订单查询、下单、通知等外部能力。
   - 通过 Function Key 和工具配置把业务接口变成 AI 可调用工具。

5. **全过程可追踪**
   - AI 回复、Prompt、工具调用、任务执行、阶段调整都有记录。
   - 便于运营复盘、问题排查和客户验收。

6. **私有化交付能力**
   - 支持部署到客户本地服务器。
   - 适合对数据安全、系统集成和内网部署有要求的企业。

## 4. 核心业务闭环

标准业务闭环如下：

```text
企微账号接入
 -> 绑定运营人员和智能体
 -> 客户进入会话
 -> 生命周期阶段启动
 -> Skill 按阶段执行
 -> AI 回复 / 工具调用 / 定时任务
 -> 客户阶段推进或人工介入
 -> 订单、成交、执行记录沉淀
 -> 运营复盘和持续优化
```

这个闭环的关键不是“AI 会聊天”，而是“AI 按企业定义的销售流程做事”。

## 5. 主要功能模块

### 5.1 工作台

用于管理层和运营负责人查看整体运行情况：

- 总客户数
- 托管微信数
- 正在聊天客户
- AI 参与订单数
- AI 参与订单金额
- 人工介入预警
- 流程阶段客户分布
- 回复平均间隔分布

### 5.2 会话中心

运营人员日常最高频使用模块：

- 按企微账号查看客户
- 查看客户聊天记录
- 人工回复
- AI 托管切换
- 查看客户基础资料
- 查看三方画像
- 查看订单信息
- 查看生命周期阶段
- 查看定时任务
- 查看 AI 回复提示词
- 查看工具调用过程
- 模拟加好友触发流程

### 5.3 企微管理

管理 AI 托管的企微账号：

- 句子通道配置
- 企微账号同步
- 在线状态查看
- 消息发送开关
- AI 托管开关
- 指定运营人员
- 绑定智能体
- 配置员工专属 Prompt
- 通知 Bot 配置

### 5.4 智能体管理

管理不同岗位的 AI 销售角色：

- 智能体名称
- 岗位定位
- 智能体说明
- 人设和业务边界
- 说话语气
- 禁止行为
- 流程配置入口

常见智能体：

- 课程顾问
- 市场顾问
- 班主任
- 客服转化顾问

### 5.5 生命周期配置

定义客户从进入私域到成交或结束的阶段路径：

- 新客阶段
- 已加好友阶段
- 信息收集阶段
- 意向判断阶段
- 课程推荐阶段
- 试听邀约阶段
- 成交转化阶段
- 售后跟进阶段

每个生命周期阶段可绑定多个销售阶段 / Skill，并配置排序、状态、跃迁条件和策略任务。

### 5.6 Skill / 销售阶段管理

Skill 是平台最核心的业务动作单元。

一个 Skill 通常包含：

- 销售阶段名称
- 逻辑描述
- 生效条件
- 结束条件
- 策略任务
- 使用模型
- 可调用工具
- 预览调试
- 执行过程查看

典型 Skill：

- 新客欢迎
- 获取学员信息
- 用户画像查询
- 课程推荐
- 异议处理
- 推动试听
- 促成下单
- 售后跟进

### 5.7 工具管理

配置 AI 可以调用的工具提示词：

- 工具名称
- 工具描述
- 提示词内容
- 启停状态

工具用于告诉 AI：什么时候可以调用某个业务能力，以及调用后如何使用结果。

### 5.8 第三方 API 配置

配置外部系统接口，使业务系统能力可以被 AI 调用：

- 用户画像查询
- 订单查询
- 下单
- 通知
- 自定义业务接口

常见 Function Key：

- `get_user_context`
- `place_order`
- `send_bot_notify`
- 自定义 Key

### 5.9 模型配置

配置 AI 使用的大模型：

- 模型供应商
- 模型名称
- API Key
- API 地址
- 启停状态

支持按平台默认或按销售阶段选择不同模型。

### 5.10 开放接口

给客户第三方系统调用：

- 查询定时任务：`GET /api/open/scheduled-tasks`
- 触发定时任务：`POST /api/open/scheduled-tasks/trigger`

适用于客户自有系统主动触发 AI 跟进任务的场景。

### 5.11 执行记录

用于排查、复盘和验收：

- 策略任务执行记录
- 第三方 API 调用记录
- 开放接口调用记录
- 流程阶段调整记录
- 完整提示词查看
- 客户、类型、关键词筛选

### 5.12 系统管理

用于后台基础权限管理：

- 账号管理
- 角色管理
- 菜单管理
- 权限分配

## 6. 标准配置流程

正确配置顺序应从底层能力到业务流程，再到企微托管上线：

```text
系统账号权限
 -> 模型配置
 -> 第三方 API 配置
 -> 工具配置
 -> 拟人化配置
 -> 智能体配置
 -> Skill 配置
 -> 生命周期配置
 -> 企微账号接入
 -> 绑定智能体
 -> 会话中心验证
 -> 执行记录复盘
```

关键原则：

- 不要先接企微账号。
- 不要一开始就开启 AI 托管。
- 先配置模型、工具、智能体、Skill 和生命周期。
- 再小范围接入企微账号。
- 最后通过会话中心和执行记录验证效果。

## 7. 官网表达重点

官网应该重点表达：

- 企微 AI 销售托管
- AI 按销售 SOP 主动跟进客户
- 生命周期流程可配置
- Skill / 销售阶段可配置
- 第三方业务系统可打通
- 人工可随时接管
- AI 回复和执行过程可追踪
- 支持私有化部署和本地服务器交付

建议主张：

> 让 AI 按你的销售流程，持续跟进每一个企微客户。

或：

> 面向私域销售团队的企微 AI 销售托管平台。

## 8. 官网不应这样表达

官网应避免以下表达：

- 不要只说“AI 聊天机器人”。
- 不要只说“智能客服”。
- 不要夸大为完全替代销售。
- 不要强调通用大模型能力，而忽略销售流程和业务闭环。
- 不要只展示炫酷 AI，而不解释企微、SOP、工具调用和可追踪性。

正确表达应突出“销售流程 + 企微托管 + AI 自动执行 + 人工可控 + 结果可追踪”。

## 10. 官网视觉与内容基调

官网应该呈现：

- 企业级
- 可信
- 清晰
- 偏 B2B SaaS
- 强调业务效率和可控性
- 避免过度娱乐化、概念化

视觉建议：

- 使用浅色企业后台风格。
- 适度使用蓝色、绿色、灰色表达智能、效率、可信。
- 多展示真实产品界面或接近真实的产品截图。
- 避免过多抽象 AI 光效和虚假科技感。
- 首屏应直接说明产品是什么、解决什么问题、适合谁。

## 11. 交付部署认知

该产品支持客户本地服务器部署，交付时需重点关注：

- 服务器环境
- 数据库与 Redis
- HTTPS 和域名
- 大模型访问
- 企微/句子互动接入
- 第三方业务系统接口
- 日志与备份
- 权限与数据安全
- 培训与验收
