# 销售助理与数据报表原型

范围：侧栏最末增加销售助理、数据报表。沿用 React/Ant Design 和观心实验室儿童心理健康课程演示内容，不接入模型或生产数据。

1. 数据层：建立291名模拟用户与沟通/意向/跟进/报名数据，所有统计从同一数据集计算。支持最近7/30天、阶段、企微角色筛选和增量对话调整；不支持的问题明确说明。
2. 销售助理：历史会话、聊天区和右侧报表预览；快捷问题、新建会话、继续调整、保存命名。保留会话与分析定义，用户账号范围限制查询和本地存储。
3. 数据报表：搜索、分类、分页、查看、重新计算、删除；保存定义与结果，支持返回助理继续调整；报表查看复用预览组件。
4. 接入菜单与角色权限，将两个入口追加至末尾。验证统计一致性、筛选、未知请求、存储隔离、构建及页面服务端渲染。

本地演示不实现真实AI、权限后端或自动定时生成。日期采用上海时区，演示数据截止2026-10-28。
