# 意向度双方案对比 Implementation Plan

**Goal:** 保留方案一，独立实现方案二的对话配置展示原型。
**Architecture:** 新增配置入口容器；旧配置页不改业务逻辑。新方案独立状态和 localStorage key，模拟启用不改变正式分档。
**Tech Stack:** React、Ant Design、现有CSS及Node验证脚本。

## 约束
- 每企业一套方案；新方案只用于原型对比，不写正式标签。
- 明确模拟对话、模拟试跑及模拟启用；不调用真实模型和甲方接口。
- 每次修改使旧试跑失效；先试跑再模拟启用，保留旧启用快照。
- 演示内容仅使用儿童心理课程业务；界面结构不绑定行业字段。
