# 平台培训演示脚本

适用项目：企微 AI 销售托管平台  
建议时长：45-60 分钟  
培训对象：客户管理层、运营负责人、销售主管、系统管理员

## 1. 开场说明

演示话术：

> 今天演示的是企微 AI 销售托管平台。系统目标是把企业微信账号、客户会话、智能体角色、生命周期阶段、销售 Skill、工具调用和第三方业务系统连接起来，让 AI 可以按照配置好的销售流程自动跟进客户，同时运营人员可以实时查看、接管和复盘。

重点说明：

- 平台不是单纯聊天工具，而是 AI 销售运营后台。
- 核心链路是：企微账号托管 -> 智能体配置 -> 生命周期推进 -> Skill 执行 -> 工具调用 -> 执行记录复盘。
- 管理员负责配置，运营负责日常监控和干预。

## 2. 登录与首页

演示步骤：

1. 打开平台地址。
2. 使用管理员账号登录。
3. 进入工作台。
4. 讲解首页指标。

讲解重点：

- 总客户数
- 托管微信数
- 正在聊天客户
- AI 参与订单数
- AI 参与订单金额
- 人工介入预警
- 流程阶段客户分布
- 回复平均间隔分布

演示话术：

> 首页主要给管理层和运营负责人看整体运营情况，包括当前客户规模、AI 托管规模、订单贡献、人工介入风险和客户所处阶段分布。

## 3. 企微账号管理

演示步骤：

1. 进入企微管理。
2. 查看企微托管账号列表。
3. 演示句子通道配置。
4. 演示消息发送开关。
5. 演示刷新同步。
6. 给企微账号指定运营人员和智能体。
7. 配置员工专属信息 Prompt。

讲解重点：

- 企微账号是 AI 托管的入口。
- 每个企微账号可以绑定智能体。
- 每个企微账号可以配置专属人设和个人信息。
- 消息发送开关用于控制是否真实触达客户。

演示话术：

> 每个企微账号都可以绑定一个智能体，也可以配置员工专属信息。AI 回复时会结合智能体人设、员工专属信息、客户资料和当前生命周期阶段生成回复。

## 4. 智能体管理

演示步骤：

1. 进入智能体管理。
2. 查看智能体列表。
3. 新增或编辑智能体。
4. 讲解智能体字段。
5. 点击进入流程配置。

讲解字段：

- 智能体名称
- 岗位定位
- 智能体说明
- 人设与业务边界
- 说话语气
- 禁止行为
- 流程阶段数
- 已配置企微数量

演示话术：

> 智能体是 AI 销售的角色模板。不同业务岗位可以配置不同智能体，例如课程顾问、班主任、市场顾问。智能体决定 AI 的身份、边界和沟通风格。

## 5. 生命周期与流程配置

演示步骤：

1. 进入某个智能体的流程配置。
2. 展示流程阶段列表。
3. 新增流程阶段。
4. 配置阶段名称、说明、排序、状态。
5. 绑定销售阶段。
6. 添加策略任务。
7. 讲解跃迁条件和任务触发时间。

讲解重点：

- 生命周期描述客户从新客到成交的过程。
- 流程阶段用于组织多个销售阶段。
- 销售阶段可以绑定到不同流程阶段。
- 策略任务负责定时触达或自动推进。

演示话术：

> 生命周期决定客户在 AI 销售流程里处于哪个阶段，每个阶段可以绑定多个销售阶段和策略任务。这样 AI 不只是回答问题，而是按业务节奏推进客户。

## 6. 销售阶段 / Skill 管理

演示步骤：

1. 进入销售阶段列表。
2. 展示查询、新增、编辑、复制、启停。
3. 进入编辑调试页面。
4. 展示逻辑描述。
5. 展示生效条件配置。
6. 展示结束条件配置。
7. 展示策略任务配置。
8. 展示模型选择。
9. 进入预览与调试。
10. 输入模拟用户消息。
11. 查看 AI 回复。
12. 点击查看执行过程。

讲解重点：

- Skill 是可复用的销售动作单元。
- 逻辑描述决定 AI 在该阶段怎么判断和回复。
- 生效条件决定什么时候进入该阶段。
- 结束条件决定什么时候退出该阶段。
- 策略任务决定什么时候主动触达客户。
- 预览调试用于上线前验证效果。

演示话术：

> Skill 可以理解为一个可复用的销售动作，比如获取学员信息、推荐课程、推动试听、处理异议。每个 Skill 都可以配置逻辑、任务、模型和工具，并且可以在上线前模拟调试。

## 7. 工具与第三方接口

演示步骤：

1. 进入工具管理。
2. 展示公共工具提示词。
3. 进入第三方 API 配置。
4. 讲解 Function Key。
5. 展示请求头、请求体模板、响应映射。
6. 说明工具如何被 Skill 调用。

讲解重点：

- 工具管理用于定义 AI 可以调用什么能力。
- 第三方 API 配置用于连接客户业务系统。
- 常见 Function Key：
  - `get_user_context`
  - `place_order`
  - `send_bot_notify`
  - 自定义工具

演示话术：

> 工具配置解决 AI 和业务系统连接的问题，比如查询客户画像、查询订单、触发下单、发送通知。Skill 中只需要约定何时调用工具，实际接口由第三方 API 配置承接。

## 8. 会话中心

演示步骤：

1. 进入会话中心。
2. 左侧选择企微账号。
3. 选择客户。
4. 查看聊天记录。
5. 查看客户资料。
6. 查看订单信息。
7. 查看生命周期阶段。
8. 查看定时任务。
9. 演示 AI 托管开关。
10. 演示人工回复。
11. 查看 AI 回复提示词。
12. 模拟加好友触发流程。

讲解重点：

- 会话中心是日常运营最高频页面。
- 运营可查看客户当前阶段。
- 运营可查看 AI 做过什么、后续要做什么。
- 必要时可人工接管。

演示话术：

> 会话中心用于日常运营监控。运营人员可以看到客户当前处于哪个阶段、AI 已经执行了哪些动作、后续还有哪些任务，也可以随时人工接管。

## 9. 执行记录

演示步骤：

1. 进入执行记录。
2. 按客户、类型、关键词查询。
3. 查看策略任务执行记录。
4. 查看第三方调用记录。
5. 查看流程阶段调整记录。
6. 查看完整提示词。

讲解重点：

- 执行记录用于排查和复盘。
- 每次 AI 回复、工具调用、阶段调整、定时任务执行都应有记录。

演示话术：

> 执行记录是平台可解释性的关键。出现回复异常、任务失败、接口失败时，可以从这里查看完整过程。

## 10. 开放接口

演示步骤：

1. 进入开放接口。
2. 展示查询定时任务接口。
3. 展示触发定时任务接口。
4. 说明第三方系统如何调用。

讲解接口：

- `GET /api/open/scheduled-tasks`
- `POST /api/open/scheduled-tasks/trigger`

演示话术：

> 如果客户自己的系统需要主动触发 AI 跟进，可以通过开放接口查询客户定时任务，并触发指定任务执行。

## 11. 系统管理

演示步骤：

1. 进入账号管理。
2. 进入角色管理。
3. 进入菜单管理。
4. 演示角色菜单权限分配。

演示话术：

> 系统管理主要面向管理员，用于控制不同岗位人员能访问哪些菜单和功能。

## 12. 收尾与答疑

收尾话术：

> 整个平台的核心闭环是：企微账号接入后，绑定智能体；智能体按照生命周期阶段推进客户；每个阶段通过 Skill 执行具体销售动作；必要时调用第三方工具；运营人员在会话中心监控和接管；所有过程进入执行记录，便于复盘和优化。

建议答疑重点：

- AI 什么时候自动回复？
- 什么情况下人工接管？
- 如何调整销售流程？
- 如何验证 AI 回复逻辑？
- 如何查看一次 AI 回复背后的 Prompt 和工具调用？
- 如何对接客户现有 CRM 或订单系统？
