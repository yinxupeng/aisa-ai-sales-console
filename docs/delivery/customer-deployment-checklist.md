# 客户本地化部署准备清单

适用项目：企微 AI 销售托管平台  
适用场景：客户本地服务器部署、私有化交付、交付前资料收集

## 1. 服务器与网络环境

客户需提供以下服务器与网络信息：

| 类别 | 需提供内容 | 说明 |
| --- | --- | --- |
| 服务器配置 | CPU、内存、磁盘、操作系统版本 | 用于评估部署规格和容量 |
| 部署方式 | 是否允许 Docker / Docker Compose | 推荐 Docker Compose，便于交付和运维 |
| 访问方式 | SSH 账号、堡垒机、VPN、白名单要求 | 用于部署、排查和升级 |
| 访问地址 | 域名或内网 IP | 例如 `https://ai-sales.xxx.com` |
| HTTPS 证书 | 证书文件或申请方式 | 如客户已有证书，需提供证书和私钥 |
| 网络策略 | 出入站端口、防火墙规则 | 涉及前端、后端、数据库、Redis、回调接口 |
| 外网访问 | 是否允许访问大模型接口 | 如不能访问外网，需提供代理或私有模型地址 |
| 内网系统 | CRM、订单系统、企微中台访问地址 | 用于第三方接口联调 |

## 2. 基础账号与权限

客户需提供：

| 类别 | 需提供内容 | 说明 |
| --- | --- | --- |
| 服务器账号 | 管理员或部署账号 | 需具备安装、启动服务权限 |
| 数据库账号 | 数据库地址、端口、账号、密码 | 如由我们初始化，则需建库权限 |
| 平台管理员 | 初始管理员姓名、手机号、登录账号 | 用于初始化后台账号 |
| 使用人员 | 管理员、运营、销售主管、客服/销售人员清单 | 用于配置账号和角色 |
| 权限要求 | 不同岗位可访问菜单范围 | 如会话中心、智能体配置、系统管理等 |

## 3. 企微与句子互动资料

客户需提供：

| 类别 | 需提供内容 | 说明 |
| --- | --- | --- |
| 句子互动账号 | App Key、企业标识、接口地址 | 用于打通企微账号与消息通道 |
| 企微账号清单 | 员工姓名、手机号、企微 ID、企微账号 | 用于初始化托管账号 |
| 同步方式 | 自动同步或手工导入 | 推荐自动同步 |
| 消息发送权限 | 是否允许平台发送消息 | 涉及真实消息触达 |
| AI 托管策略 | 默认开启或人工开启 | 决定上线初始策略 |
| 通知 Bot | 企微机器人 Webhook | 用于异常、人工介入通知 |
| 回调接口 | 加好友、客户消息、发送结果回调 | 用于驱动生命周期和执行记录 |

## 4. 大模型配置资料

客户需提供：

| 类别 | 需提供内容 | 说明 |
| --- | --- | --- |
| 模型供应商 | OpenAI、DeepSeek、火山、MiniMax、私有模型等 | 确定模型接入方式 |
| API Key | 正式或测试 Key | 部署后配置到模型管理 |
| API Base URL | 模型接口地址 | 如走代理需提供代理地址 |
| 默认模型 | 默认使用的模型名称 | 例如 `deepseek-chat` |
| 调用限制 | 并发、QPS、额度、内容安全限制 | 用于设置运行边界 |
| 数据安全 | Prompt、聊天内容是否允许发往外部模型 | 如不允许，需提供私有化模型 |

## 5. 第三方业务系统接口

客户需提供接口文档、测试环境、鉴权方式和示例数据：

| 接口 | 是否必需 | 说明 |
| --- | --- | --- |
| 用户画像查询 | 必需 | AI 判断客户信息和销售策略 |
| 客户资料查询 | 必需 | 获取姓名、手机号、标签、来源等 |
| 订单查询 | 建议必需 | 展示订单信息和成交状态 |
| 下单接口 | 视业务而定 | 如果 AI 需要辅助下单，则必需 |
| 支付/报名状态 | 视业务而定 | 用于判断成交和阶段结束 |
| 客户阶段同步 | 视业务而定 | 如需同步回 CRM，则必需 |
| 通知接口 | 可选 | 用于人工介入、异常提醒 |

每个接口需明确：

- 请求地址
- 请求方式
- Header
- 鉴权方式
- 请求参数
- 响应字段
- 错误码
- 超时时间
- 是否支持重试
- 是否具备测试数据

## 6. 业务配置资料

客户需提供业务规则和销售 SOP：

| 类别 | 需提供内容 |
| --- | --- |
| 智能体角色 | 课程顾问、班主任、市场顾问等 |
| 人设说明 | 岗位定位、沟通风格、禁止行为 |
| 生命周期阶段 | 新客、已加好友、意向沟通、试听邀约、成交等 |
| 阶段目标 | 每个阶段 AI 需要完成的目标 |
| 销售阶段 / Skill | 每个阶段对应的销售动作 |
| 定时任务规则 | 加好友后多久欢迎、多久跟进、多久提醒 |
| 人工介入规则 | 投诉、敏感承诺、价格异议、强烈成交意向等 |
| 标准话术 | 推荐话术、禁用话术、业务边界 |

## 7. 运维与安全要求

客户需确认：

- 日志保留周期
- 数据备份周期
- 是否需要审计日志
- 是否需要手机号、姓名、聊天内容脱敏
- 是否允许导出数据
- 是否接入统一登录
- 是否要求 IP 白名单
- 是否需要等保、安全扫描或渗透测试
- 故障联系人和响应机制

## 8. 我方交付内容

我方负责：

- 部署包或镜像交付
- 服务部署与启动
- 数据库初始化
- Nginx / HTTPS / 跨域配置
- 管理员账号初始化
- 菜单、角色、权限初始化
- 模型配置指导
- 企微/句子互动联调
- 第三方 API 联调
- 演示数据准备
- 平台培训
- 验收支持
- 部署文档、使用手册、联调文档、验收清单交付
