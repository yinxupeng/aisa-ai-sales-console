# 平台运营中心一期产品方案

经讨论确认：签约后由我方手动录入企业，配置企业管理员、企微托管席位额度和有效期。平台运营端与客户企业端同仓库管理、分别登录及构建，保留现有企业端功能。

## 范围与入口
- `platform.html`：我方运营中心，企业管理（包含托管席位授权）、平台账号、操作日志。
- `index.html`：原企业端；`?enterprise=企业ID#wecomAccounts` 打开指定企业的席位分配场景。
- `portal.html`：双入口演示页。
- 平台使用现有 Ant Design 风格；新增模块采用 TypeScript，既有 JSX 文件不整体迁移。

## 核心规则
- 企业端企微账号管理只展示企业可托管账号数、已分配/剩余数量与统一到期时间，移除逐账号到期列与到期筛选，不保存独立开通日期。批量分配/释放仅为多选操作，不产生授权批次。
- 席位管理统一收敛至企业列表与企业详情，不再提供独立的“托管席位管理”菜单或页面；旧席位页面链接跳转至企业管理。
- 企业详情与列表统一使用“调整席位”入口，同时修改席位数量和到期时间，不单独设置“续期”按钮。
- 新建企业分企业信息、管理员、服务配置三步，支持保存待开通、正式开通、交付信息复制。
- 企业配置授权与企业端已生效授权分别记录。配置后待同步，通过“模拟同步授权”演示企业端生效。
- 一个企微账号绑定一个席位。离线、暂停 AI 不释放席位，明确释放才返还额度。
- 席位授权只配置数量和企业统一到期时间，不设置开始时间，也不按每个席位的分配时间计算有效期；新增、晚分配或扩容席位均沿用该企业的统一到期时间，续期时统一调整。
- 调低额度不能低于已绑定数量；生效时再次检查，防止待同步期间新增分配导致超额。
- 未开通、停用或已过期服务禁止新增分配及开启 AI，允许查看及释放席位。已开通且未到期的授权同步后即可使用，不再存在按开始日期等待生效的状态。
- 企业端分配账号、负责人、运行状态与平台使用明细共用同一企业数据。
- 平台运营角色可管理企业与席位；平台账号管理仅超级管理员可操作。
- 首次企业登录设置演示密码，管理员重置后重新激活。演示账号不连接真实身份系统。

## 演示与边界
纯前端产品原型，企业及席位数据保存在同源浏览器 localStorage，支持同窗口即时更新及跨标签页同步。授权同步、企微同步均为明确标记的模拟操作。无真实后台鉴权、授权签发、消息发送、短信邮件或远程部署控制。正式交付需服务端租户隔离及鉴权。

推荐演示：登录 → 新建企业并授权 10 席 → 模拟授权同步 → 企业端首次激活 → 模拟接入账号并分配席位 → 平台调整额度 → 模拟同步 → 企业端查看新额度。
