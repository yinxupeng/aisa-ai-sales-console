# 客户咨询与扫码留资

## 已确认范围
平台运营中心增加与企业管理同级的“客户咨询”，位于系统管理之后。保持现有 Ant Design 风格。客户无需登录即可填写移动端咨询表单，客服在后台分配负责人、记录跟进、标记成交，再复用现有企业开通流程。

## 页面与规则
- `consultation.html`：姓名、手机号必填；企业名称、预计账号数、需求描述选填。提交成功明确反馈并防止同一次请求重复提交。
- 咨询列表：搜索、跟进状态/负责人/开通状态筛选；列表展示联系方式、企业、需求、提交时间、最近跟进、关联企业。
- 详情抽屉：原始资料、客服负责人、待联系/跟进中/已成交/无效咨询、跟进记录。
- 已成交可开通企业；预填联系人、电话、公司、预计席位数。咨询与新企业建立关联；已关联或已存在来源企业时不允许重复创建。
- 二维码弹窗：预览、复制链接、下载二维码、编辑表单地址、恢复默认链接。二维码从链接生成，编辑链接后同步更换；原有二维码图片不会自动改变。
- 不自动标记付款、不发真实消息；成交由客服人工确认。

## 演示边界
沿用本地前端演示：咨询存储与平台其他数据隔离，均保存于同源浏览器；不清理现有企业数据。手机布局适配不等于跨设备收集；正式使用需部署公共页面与服务端接口。二维码管理明确提示本地/文件链接限制。外部替换的链接需指向部署后的同一表单，外部系统不会自动回流数据。

## 实施与验证
1. 咨询纯函数：校验、幂等提交、跟进、关联企业；先测试后实现。
2. 独立咨询存储兼容旧项目；现有企业开通添加来源及防重复。
3. 咨询后台、二维码管理与移动表单；独立构建入口。
4. 验证提交、重复提交、跟进、成交前禁止开通、预填、开通后关联、缓存兼容、QR 链接校验；构建和页面渲染检查。
