# 用户洞察与建议 PRD（简版）

页面位置：人机协作 → 用户洞察与建议。综合用户档案与历史聊天，生成聊天总结和用户洞察，方便人工了解用户并跟进。

## 一、用户洞察与建议首页

### 1. 顶部操作

- 自动更新时间：展示当前配置的每日执行时间。
- 洞察生成配置：点击进入配置页面。
- 洞察生成记录：点击进入独立的生成记录页面。

### 2. 时间与范围

- 统计时间范围：最近一次生成任务对应的统计区间。
- 分析人群：当前企微账号下、符合配置筛选条件的用户范围。
- 最近生成：最近一次生成任务的完成时间；没有记录时显示“暂无”。
- 下次生成时间：根据保存的执行时间，展示下一次计划生成时间。

### 3. 数据汇总

- 总用户数：当前企微账号下的用户总数，按用户去重。
- 有效沟通用户数：历史上至少有一条客户回复消息的用户数。
- 应该洞察用户数：有效沟通用户中，符合用户阶段、托管状态和聊天条数条件的人数。
- 成功生成洞察数：本次任务中，聊天总结和用户洞察都生成成功的人数。

四张卡片展示同一企微账号、同一次生成任务对应的数据。“大于 X 条”按严格大于计算；聊天条数建议只统计客户消息，不包含 AI、人工和系统消息。

### 4. 搜索与列表

支持搜索用户姓名、聊天总结和用户洞察；支持按当前阶段筛选。两个条件同时生效，点“重置”恢复全部用户。筛选后分页展示，默认每页 6 人。

- 用户：客户姓名。
- 所属企微号：客户归属的企微账号名称。
- 当前阶段：开课前、第一节课、第二节课、第三节课、第四节课、第5节课、课后。
- 历史聊天：截至本次生成时的历史聊天条数。
- 聊天总结：所选聊天总结 Skill 生成的历史沟通摘要。
- 用户洞察：所选用户洞察 Skill 生成的“用户背景、用户洞察、关键风险、销售建议”四段内容；不展示提示词摘要。
- 操作：点击“查看”进入该用户在会话中心的聊天。

## 二、洞察生成配置页

页面顶部可返回洞察结果或保存配置。一个企微账号使用一份当前配置；打开页面时回填已保存的内容。

### 1. 选择执行节奏

- 执行节奏：固定为“每天执行”。
- 每日执行次数：每天 1 次或每天 2 次，默认 1 次。
- 执行时间：按执行次数显示 1 个或 2 个时间选择器，默认 18:00。
- 执行预览：根据所选时间即时显示“每天 18:00”或“每天 09:00、18:00”。

每天两次时应选择两个不同的时间。修改时间后，首页“下次生成时间”按新配置更新。

### 2. 选择用户范围

- 用户阶段：全部阶段（默认）、开课前、第一节课、第二节课、第三节课、第四节课、第5节课、课后。
- 托管状态：不限（默认）、已托管、未托管。
- 历史聊天数：不限（默认），或大于 1～20 条中的指定数值。
- 当天聊天数：不限（默认），或大于 1～20 条中的指定数值。

四个条件同时生效。“不限”不增加该项限制；“当天聊天数”按最近一个执行周期内的用户消息统计。

### 3. 分析用户数据来源

固定为“用户档案、历史聊天记录”，两个选项默认选中且不可取消。

### 4. 选择分析的skill

- 聊天总结：选择用于生成聊天总结的 Skill。
- 用户洞察：选择用于生成用户洞察的 Skill。

两个 Skill 分别选择，选择后显示 Skill 说明。页面不填写提示词；输出要求由所选 Skill 决定。涉及儿童心理健康内容时，不作医疗诊断、不承诺疗效。

## 三、洞察生成记录页

通过首页“洞察生成记录”进入，列表按执行时间从近到远展示。列表字段为：执行时间、执行周期、分析范围、应该洞察用户数、成功生成洞察数、执行状态。列表不设置“操作”列。

点击一条记录，右侧展示该次任务的执行时间、配置条件、处理人数、成功人数、耗时，以及本次生成摘要和重点洞察。顶部“返回用户洞察与建议”回到首页。历史记录展示当时的执行结果，不随新配置改变。

## 四、会话中心同步展示

在客户详情侧边栏“销售策略”Tab 中，依次展示电话沟通总结、聊天总结、用户洞察。每部分展示生成时间和对应内容。聊天总结与用户洞察取该客户最新的生成结果；没有结果时显示“暂无生成结果”。

用户洞察支持编辑、保存和取消；人工保存后的内容展示在该客户侧边栏。电话沟通总结和聊天总结只读。点击用户综合洞察列表的“查看”，应打开同一客户的聊天及详情。

> 当前页面为原型，列表数字和文字是模拟数据；真实定时生成、Skill 调用及持久化需后续接入。
