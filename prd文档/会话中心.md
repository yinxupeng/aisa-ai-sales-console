# PRD：会话中心选中功能逻辑

> 文档版本：V1.0  
> 更新时间：2026-09-03  
> 模块路径：会话中心  
> 覆盖范围：仅覆盖截图红框选中的功能区域  
> 适用对象：产品、前端、后端、测试、实施交付  

## 1. 文档范围

本文只描述会话中心本版本截图中选中的功能逻辑，不扩展未选中的页面能力。

覆盖功能：

1. 会话筛选区
2. 会话列表客户卡片
3. 会话列表分页
4. 聊天区顶部动态流程阶段条
5. 客户详情抽屉中的销售策略 Tab
   - 用户对话数据
   - 用户上课信息
   - 策略智能体输出结果
   - 用户洞察与销售建议编辑

不覆盖功能：

- 高级筛选
- 用户信息 Tab 完整字段逻辑
- 课程信息 Tab 完整订单逻辑
- 流程阶段 Tab 完整详情逻辑
- 人工回复输入框
- 消息发送
- AI 托管开关
- 同步资料按钮
- 群聊成员管理
- 会话批量操作

## 2. 业务目标

1. 销售或运营可以通过筛选区快速定位目标客户会话。
2. 会话列表在进入聊天前提供足够的客户判断信息。
3. 分页支持大量客户会话的分批浏览。
4. 聊天区顶部直接展示客户当前课程 / 角色流程阶段，辅助判断当前跟进节点。
5. 销售策略 Tab 汇总用户对话数据、上课信息和策略智能体输出，帮助销售快速判断下一步沟通策略。
6. 人工可编辑策略智能体输出结果，保存后覆盖 AI 输出。

## 3. 页面结构

```text
会话中心
  ├─ 会话筛选区
  ├─ 会话列表
  │   ├─ 客户卡片
  │   └─ 分页
  └─ 聊天区
      ├─ 动态流程阶段条
      └─ 客户详情抽屉
          └─ 销售策略 Tab
              ├─ 用户对话数据
              ├─ 用户上课信息
              └─ 策略智能体输出结果
```

## 4. 会话筛选区

### 4.1 功能说明

会话筛选区位于会话列表顶部，用于快速筛选当前企微账号下的客户会话。

### 4.2 筛选项

| 筛选项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 搜索客户、群或消息 | 搜索框 | 空 | 支持按客户姓名、群名称、最近消息内容搜索 |
| 筛选托管 | 下拉选择 | 全部 | 支持筛选已托管、未托管客户 |
| 筛选阶段 | 下拉选择 | 全部 | 支持按客户当前流程阶段筛选 |
| 选择客户标签 | 标签选择框 | 空 | 支持从统一标签库选择客户标签 |
| 重置 | 按钮 | - | 清空当前筛选条件 |
| 搜索 | 按钮 | - | 执行搜索并定位结果 |

### 4.3 交互规则

1. 搜索框支持输入客户姓名、群名称或消息关键词。
2. 点击搜索后，系统按当前筛选条件刷新会话列表。
3. 点击重置后，清空关键词、托管状态、流程阶段和客户标签。
4. 筛选条件之间为“同时满足”关系。
5. 任一筛选条件变化后，会话分页回到第 1 页。
6. 筛选结果为空时，会话列表展示空状态。
7. 本版本不提供高级筛选。

### 4.4 客户标签筛选规则

1. 客户标签来源于标签库管理模块的正式标签库。
2. 会话中心不维护独立标签枚举。
3. 选择客户标签后，只展示命中所选标签的客户会话。
4. 标签展示名称应与标签库一致。

## 5. 会话列表客户卡片

### 5.1 功能说明

会话列表展示当前企微账号下满足筛选条件的客户或群会话。每个客户以卡片形式展示，帮助销售进入聊天前快速判断客户状态。

### 5.2 展示字段

| 字段 | 说明 |
| --- | --- |
| 头像 | 客户头像或群头像 |
| 客户名称 | 客户备注名或客户昵称 |
| 手机号 | 脱敏手机号，例如 138****7788 |
| 微信昵称 | 客户微信昵称 |
| 添加时间 | 客户添加企微时间，例如 15天前添加、06-13 添加 |
| 最近消息摘要 | 最近一条有效会话内容摘要 |
| 最近消息时间 | 最近一条消息时间，格式示例：05-27 10:20:00 |
| 发送方来源 | 用户发送、AI发送、员工发送 |
| 人工接管标识 | 需要人工关注时展示红色人工图标 |

### 5.3 发送方来源规则

| 消息来源 | 列表展示 |
| --- | --- |
| 客户发送 | 用户发送 |
| AI 托管发送 | AI发送 |
| 人工销售 / 班主任发送 | 员工发送 |

### 5.4 人工接管标识规则

当客户会话需要人工关注时，在卡片右侧展示人工接管标识。

触发条件包括：

1. 当前会话需要人工确认发送。
2. 当前会话已进入人工接管状态。
3. 当前会话命中需要人工处理的业务状态。

### 5.5 交互规则

1. 点击客户卡片后，右侧聊天区切换到该客户会话。
2. 当前选中的客户卡片高亮展示。
3. 最近消息过长时省略展示。
4. 鼠标悬浮最近消息时，可展示完整消息、消息时间和发送方来源。
5. 手机号为空时不展示手机号。
6. 群聊卡片可展示群标识，且不展示手机号。

## 6. 会话列表分页

### 6.1 功能说明

会话列表底部提供分页能力，用于支持一个企微账号下存在大量客户会话的场景。

### 6.2 分页规则

| 字段 | 说明 |
| --- | --- |
| 当前页 | 当前所在页码 |
| 每页数量 | 默认 10 条 |
| 可选每页数量 | 10 / 20 / 50 |
| 上一页 / 下一页 | 支持前后翻页 |

### 6.3 交互规则

1. 默认展示第 1 页，每页 10 条。
2. 切换页码后，会话列表展示对应页数据。
3. 切换每页数量后，从第 1 页开始展示。
4. 筛选条件变化后，分页回到第 1 页。
5. 当前页超过筛选后总页数时，自动回退到可用页。

## 7. 动态流程阶段条

### 7.1 功能说明

动态流程阶段条展示当前客户所在的课程 / 角色流程，用于帮助销售判断客户处于哪个服务节点。

### 7.2 阶段来源

流程阶段根据客户购买的课程或绑定的角色流程动态生成。

阶段来源包括：

1. 客户购买课程对应的课程流程。
2. 客户绑定角色对应的服务流程。
3. 企业配置的业务流程。

### 7.3 展示字段

| 字段 | 说明 |
| --- | --- |
| 阶段名称 | 例如 A类课前、A类第一节课、A类课后，实际名称由流程配置决定 |
| 阶段时间 | 阶段对应的时间范围或计划时间 |
| 当前阶段 | 当前客户所在阶段，高亮展示 |
| 阶段状态 | 已完成、当前、未开始 |
| 课程状态图标 | 已到课、已排课未上课、未到课等 |

### 7.4 状态规则

| 状态 | 展示逻辑 |
| --- | --- |
| 已完成 | 客户已完成该阶段 |
| 当前阶段 | 客户当前正在该阶段 |
| 未开始 | 客户尚未进入该阶段 |
| 已上课 | 课程阶段已完成上课 |
| 已排课未上课 | 已有上课安排，但客户尚未完成上课 |
| 未到课 | 客户未参加该课节 |
| 待定 | 暂无明确课程时间 |

### 7.5 悬浮详情

鼠标悬浮阶段时，展示阶段详情。

字段包括：

| 字段 | 说明 |
| --- | --- |
| 流程阶段 | 当前阶段名称 |
| 阶段进度 | 当前阶段序号 / 总阶段数 |
| 阶段开始 | 阶段开始时间 |
| 阶段结束 | 阶段结束时间 |
| 上课形式 | 直播、录播或空 |
| 课程状态 | 已结束、已开始、未开始等 |
| 是否到课 | 已到课、未到课 |
| 上课总时长 | 实际上课或观看时长 |

### 7.6 业务规则

1. 阶段条不写死为固定 A 类课流程。
2. 不同客户可以展示不同阶段数量、阶段名称和阶段状态。
3. 课程类阶段需要展示上课形式、课程状态、是否到课和上课总时长。
4. 非课程类阶段可不展示课程相关字段，或展示为空。
5. 当前阶段必须有明确高亮。
6. 已完成、当前、未开始状态需要有明显视觉区分。

## 8. 销售策略 Tab

### 8.1 功能说明

销售策略 Tab 位于客户详情抽屉中，用于展示策略智能体基于客户会话和上课信息生成的销售策略结果。

该 Tab 只覆盖截图选中区域，包括：

1. 用户对话数据
2. 用户上课信息
3. 策略智能体输出结果
4. 用户洞察与销售建议编辑

## 9. 用户对话数据

### 9.1 展示字段

| 字段 | 说明 |
| --- | --- |
| 用户发送 | 客户主动发送的消息数量 |
| 用户接收 | 客户收到的消息数量，包含 AI 消息 + 人工销售消息 |

### 9.2 统计规则

1. 用户发送只统计客户侧发出的有效消息。
2. 用户接收统计客户收到的有效消息。
3. 用户接收包含 AI 自动回复和人工销售 / 班主任消息。
4. 系统通知类消息不计入用户发送或用户接收。
5. 发送失败的消息不计入用户接收。

## 10. 用户上课信息

### 10.1 功能说明

用户上课信息展示当前客户体验课课节情况，用于辅助销售判断客户体验进度和转化时机。

### 10.2 展示字段

| 字段 | 说明 |
| --- | --- |
| 课节名称 | 课节标题，例如第1节、第2节 |
| 上课形式 | 录播、直播 |
| 课程状态 | 已结束、已开始、未开始 |
| 是否到课 | 已到课、未到课 |
| 上课总时长 | 已上课程展示实际时长，未上课程展示待上课 |

### 10.3 业务规则

1. 当前截图版本展示体验课共 4 节课。
2. 已完成上课的课节展示“已到课”和实际时长。
3. 已开始但客户未到课的课节展示“未到课”和“待上课”。
4. 未开始课节展示“未开始”和“待上课”。
5. 上课信息为策略智能体生成销售策略的重要输入。

## 11. 策略智能体输出结果

### 11.1 功能说明

策略智能体输出结果展示 AI 基于客户对话数据、上课信息和客户状态生成的销售判断。

### 11.2 展示字段

| 字段 | 说明 |
| --- | --- |
| 最近更新 | 策略结果最后更新时间 |
| 来源 | 生成策略结果的策略智能体 |
| 用户洞察与销售建议 | 策略正文 |

### 11.3 策略正文内容

策略正文建议包含：

1. 孩子情况
2. 用户洞察
3. 关键风险
4. 销售建议
5. 给会话智能体的提示词摘要

### 11.4 编辑规则

1. 点击“编辑”后，用户洞察与销售建议进入编辑状态。
2. 编辑状态下展示文本输入区域。
3. 点击保存后，人工编辑内容覆盖 AI 输出。
4. 保存成功后，页面展示人工编辑后的内容。
5. 点击取消后，放弃本次编辑，恢复编辑前内容。
6. 人工覆盖后，不在当前页面展示 AI 原始版本对比。

### 11.5 业务规则

1. AI 输出仅作为销售跟进参考。
2. 人工编辑后的内容优先级高于 AI 输出。
3. 策略内容不直接发送给客户。
4. 策略内容服务于销售判断和后续会话智能体回复策略。

| 流程阶段 | 支持阶段筛选和阶段条展示 |

### 12.2 流程阶段条依赖

| 数据 | 用途 |

## 13. 异常与边界场景

| 场景 | 处理方式 |
| --- | --- |
| 筛选后无客户 | 会话列表展示空状态 |
| 客户手机号为空 | 卡片不展示手机号 |
| 最近消息为空 | 展示暂无最近沟通 |
| 客户无流程阶段 | 阶段条展示空状态或不展示 |
| 阶段名称过长 | 阶段名称省略展示，悬浮展示完整内容 |
| 课程状态未返回 | 课程状态展示待定 |
| 上课时长未返回 | 展示待上课或空 |
| 策略智能体暂无输出 | 销售策略区域展示暂无策略 |
| 编辑策略保存失败 | 保留编辑内容并提示保存失败 |
| 标签库无可选标签 | 标签选择框展示空状态 |

## 14. 验收标准

### 14.1 会话筛选区

1. 页面展示搜索框、筛选托管、筛选阶段、选择客户标签、重置、搜索。
2. 不展示高级筛选入口。
3. 输入关键词后可以筛选客户、群或消息。
4. 选择托管状态后，会话列表按已托管 / 未托管过滤。
5. 选择流程阶段后，会话列表按客户当前阶段过滤。
6. 选择客户标签后，会话列表按标签过滤。
7. 点击重置后清空筛选条件。
8. 筛选条件变化后分页回到第一页。

### 14.2 会话列表

1. 客户卡片展示头像、客户名称、手机号、微信昵称、添加时间、最近消息摘要、最近消息时间和发送方来源。
2. 用户消息展示为“用户发送”。
3. AI 消息展示为“AI发送”。
4. 人工销售消息展示为“员工发送”。
5. 需要人工关注的客户展示人工接管标识。
6. 点击客户卡片后，右侧聊天区切换为该客户。
7. 当前选中客户卡片高亮。

### 14.3 分页

1. 默认每页展示 10 条。
2. 支持切换 10 / 20 / 50 条。
3. 支持上一页和下一页。
4. 筛选条件变化后回到第 1 页。

### 14.4 动态流程阶段条

1. 阶段条根据客户购买课程或角色流程动态生成。
2. 当前阶段高亮展示。
3. 已完成、当前、未开始状态样式区分明确。
4. 课程阶段展示课程状态、是否到课和上课总时长。
5. 悬浮阶段时展示阶段详情。
6. 不同客户可以展示不同流程阶段。

### 14.5 销售策略 Tab

1. 销售策略 Tab 展示用户对话数据。
2. 用户发送统计客户发送消息数。
3. 用户接收统计 AI 消息 + 人工销售消息。
4. 销售策略 Tab 展示用户上课信息。
5. 用户上课信息展示课节名称、上课形式、课程状态、是否到课、上课总时长。
6. 销售策略 Tab 展示策略智能体输出结果。
7. 策略结果展示最近更新时间和来源智能体。
8. 点击编辑后可修改用户洞察与销售建议。
9. 保存后人工内容覆盖 AI 输出。
10. 取消编辑后恢复原内容。

## 15. 待企业实施确认项

以下仅为企业落地时需要确认的数据口径，不影响当前选中功能逻辑：

1. 客户基础信息字段来源。
2. 课程 / 角色流程配置来源。
3. 体验课课节数据来源。
4. 用户发送和用户接收统计是否排除撤回、失败、系统消息。
5. 策略智能体输出结果人工覆盖后，后端是否保留 AI 原始版本用于审计。
