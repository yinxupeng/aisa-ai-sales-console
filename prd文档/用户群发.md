# PRD：用户群发

> 文档版本：V1.0 技术研发版  
> 更新时间：2026-09-03  
> 模块路径：用户运营 / 用户群发  
> 适用对象：产品、前端、后端、测试、实施交付  

## 1. 模块定位

用户群发是企微智能销售平台的运营触达模块，用于运营、销售或班主任按客户状态、服务阶段和客户标签圈选人群，通过已授权企微账号向可触达客户发送文本、图片、视频、文件或链接内容。

一期定位为人工创建群发任务，不做 AI 自动生成群发内容，不做复杂审核流。由于该模块会真实触达客户，技术实现必须明确发送对象、发送账号权限、任务状态流转、暂停 / 取消 / 删除规则、失败记录和操作审计。

## 2. 业务目标

1. 支持运营人员快速创建面向目标客户的群发任务。
2. 支持按标签、状态、服务阶段等条件圈选客户，并排除不适合触达的人群。
3. 支持立即发送和定时发送。
4. 支持按客户所属销售发送，也支持选择当前登录账号授权的企微账号发送。
5. 群发只发送给可触达客户，避免向已删除企微、不可联系或风险禁止触达客户发送。
6. 支持任务查看、编辑、复制、暂停、取消和删除。
7. 保留已发送任务和发送结果记录，便于追溯。

## 4. 核心原则

### 4.1 只发送给可触达客户

群发任务最终发送对象必须经过可触达校验。

不可触达客户不进入实际发送队列，包括但不限于：

- 已删除企微
- 企微关系异常
- 客户不可联系
- 当前账号无权限触达
- 客户所属企微账号未连接
- 客户命中禁止触达风险标记
- 客户已退群或外部联系人状态异常

### 4.2 标签库统一原则

群发人群选择必须使用正式标签库。

用户群发模块不能维护独立标签枚举。目标标签、排除标签均从标签库读取。

### 4.3 发送账号权限原则

指定企微账号发送时，只允许选择当前登录账号下已授权的企微账号，支持多选。

不允许选择无权限企微账号，不允许跨企业选择企微账号。

### 4.4 已发送记录不可删除

未发送任务可以删除。已经产生发送行为的任务不支持删除，只能保留记录。

已发送行为包括：

- 发送中
- 已完成
- 部分成功
- 发送失败但已创建发送记录

### 4.5 立即发送即时触发

创建或编辑任务时，如果发送方式选择“立即发送”，点击保存后立即触发发送，不再只是保存草稿。

前端按钮和二次确认交互需清楚表达该操作会真实触达客户。

## 5. 用户角色与权限

| 角色 | 使用目标 | 可操作范围 |
| --- | --- | --- |
| 运营管理员 | 创建面向指定人群的运营群发 | 查看、创建、编辑、复制、暂停、取消、删除未发送任务 |
| 销售主管 | 面向销售客户池发起跟进群发 | 查看本部门任务，创建和管理有权限客户范围内任务 |
| 班主任主管 | 面向服务中客户发起课程提醒或复盘群发 | 查看本部门任务，创建和管理有权限客户范围内任务 |
| 普通销售 / 班主任 | 查看或执行自己客户范围内群发 | 按权限查看，是否可创建由后台权限控制 |

权限落地时需同时校验：

- 页面权限
- 客户数据权限
- 标签数据权限
- 企微账号发送权限
- 素材访问权限

## 7. 任务状态机

### 7.1 状态定义

| 状态 | 说明 | 是否可编辑 | 是否可删除 | 是否可暂停 | 是否可取消 |
| --- | --- | --- | --- | --- | --- |
| 草稿 | 已保存但未进入发送计划 | 是 | 是 | 否 | 是 |
| 待发送 | 定时任务已创建，等待发送 | 是 | 是 | 是 | 是 |
| 发送中 | 已开始执行发送 | 否 | 否 | 是 | 是 |
| 已暂停 | 任务暂停，未继续发送 | 是 | 否 | 否 | 是 |
| 已取消 | 任务被取消，不再发送 | 否 | 否 | 否 | 否 |
| 已完成 | 全部可发送对象处理完成 | 否 | 否 | 否 | 否 |
| 发送失败 | 任务执行失败或全部发送失败 | 否 | 否 | 否 | 否 |
| 部分成功 | 部分客户发送成功，部分失败 | 否 | 否 | 否 | 否 |

### 7.2 状态流转

```text
创建草稿
  -> 编辑
  -> 删除 / 取消 / 保存为待发送 / 立即发送

创建定时发送任务
  -> 待发送
  -> 暂停
  -> 已暂停
  -> 编辑后恢复待发送 / 取消

创建立即发送任务
  -> 保存后直接进入发送中
  -> 已完成 / 部分成功 / 发送失败

发送中
  -> 暂停
  -> 已暂停
  -> 取消
  -> 已取消
  -> 已完成 / 部分成功 / 发送失败
```

### 7.3 删除、暂停、取消规则

删除：

1. 草稿、待发送任务可删除。
2. 已产生发送记录的任务不可删除。
3. 删除后任务不在普通列表展示，但后台可保留操作审计。

暂停：

1. 待发送任务可以暂停。
2. 发送中任务可以暂停，暂停后未发送客户不再继续发送。
3. 已暂停任务可以编辑发送时间、内容、人群后恢复待发送。

取消：

1. 草稿、待发送、发送中、已暂停任务可以取消。
2. 取消后任务不可恢复。
3. 发送中任务取消后，已发送客户保持发送结果，未发送客户标记为已取消。

## 8. 功能需求

### 8.1 任务列表

列表字段：

| 字段 | 说明 |
| --- | --- |
| 群发名称 | 内部任务名称 |
| 业务角色 | 全部角色、销售、班主任、市场 |
| 目标人群 | 全部客户或筛选条件摘要 |
| 预计发送人数 | 根据筛选条件和可触达校验计算 |
| 发送时间 | 立即发送或定时发送时间 |
| 发送账号 | 按客户所属销售发送或指定企微账号发送 |
| 发送状态 | 草稿、待发送、发送中、已暂停、已取消、已完成、发送失败、部分成功 |
| 创建人 | 创建任务的用户 |
| 更新时间 | 最近更新时间 |
| 操作 | 查看、编辑、复制、暂停、取消、删除 |

筛选条件：

- 群发名称关键词
- 发送状态
- 业务角色

操作规则：

1. 查看：所有有权限任务均可查看。
2. 编辑：草稿、待发送、已暂停任务可编辑。
3. 复制：复制为新草稿，不复制原任务发送记录。
4. 删除：仅草稿、待发送任务可删除。
5. 暂停：待发送、发送中任务可暂停。
6. 取消：草稿、待发送、发送中、已暂停任务可取消。

### 8.2 创建 / 编辑群发任务

打开方式：右侧抽屉。

字段：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 群发名称 | 输入框 | 是 | 内部可见任务名称 |
| 群发说明 | 输入框 | 否 | 内部备注，例如“A 类课课后未报名回访” |
| 业务角色 | 单选 | 是 | 全部角色、销售、班主任、市场 |
| 选择客户 | 单选 | 是 | 全部客户、筛选客户 |
| 群发内容 | 文本框 | 是 | 发送给客户的正文内容 |
| 素材 | 上传 / 选择 | 否 | 图片、视频、文件、素材库、远程链接 |
| 发送方式 | 单选 | 是 | 立即发送、定时发送 |
| 定时发送时间 | 日期时间 | 条件必填 | 选择定时发送时必填 |
| 发送账号 | 单选 | 是 | 按客户所属销售发送、指定企微账号发送 |
| 指定企微账号 | 多选 | 条件必填 | 当前登录账号已授权企微账号 |

校验规则：

1. 群发名称不能为空。
2. 群发内容不能为空。
3. 群发内容最多 5000 字。
4. 选择定时发送时，必须选择未来时间。
5. 选择指定企微账号发送时，必须至少选择一个企微账号。
6. 指定企微账号只能从当前登录账号已授权账号中选择。
7. 最终预计发送人数为 0 时，不允许提交发送。

### 8.3 选择客户

支持两种模式：

#### 8.3.1 全部客户

选择“全部客户”时：

- 不展示标签选择
- 不展示状态筛选
- 系统发送给当前权限范围内的全部可触达客户
- 预计发送人数按可触达客户计算

#### 8.3.2 筛选客户

选择“筛选客户”时，展示筛选条件：

| 条件 | 说明 |
| --- | --- |
| 托管状态 | 全部托管状态、已托管、未托管 |
| 所处阶段 | 全部阶段、了解阶段、定义用户、提升认知、催单阶段、完单阶段 |
| 标签 | 选择目标客户标签 |
| 排除客户 | 选择需要排除的客户标签 |

标签筛选规则：

1. 标签来自正式标签库。
2. 标签选择使用统一标签选择弹窗。
3. 目标标签支持“满足其一”和“同时满足”。
4. 排除标签命中后，该客户不进入发送队列。
5. 排除标签优先级高于目标标签。

### 8.4 可触达客户口径

群发任务提交后，系统需基于筛选结果进一步做可触达校验。

可触达客户需同时满足：

1. 当前登录账号有权限查看和触达该客户。
2. 客户存在有效企微关系。
3. 客户未删除企微。
4. 客户对应发送企微账号已连接且可发送。
5. 客户未命中禁止触达风险标记。
6. 客户不在本任务排除标签命中范围。

不可触达客户处理：

- 不进入实际发送队列
- 计入不可触达数量
- 查看任务时展示不可触达原因汇总

### 8.5 素材与内容

支持内容类型：

- 文本
- 图片
- 视频
- 文件
- 远程链接
- 素材库资源

业务规则：

1. 文本内容必填。
2. 素材可选。
3. 同一任务可携带多个素材，具体数量和大小受消息通道限制。
4. 素材库资源需校验当前登录账号访问权限。
5. 远程链接需校验格式。
6. 如果消息通道不支持某类素材，提交时应提示并阻止发送。

### 8.6 发送账号

支持两种模式：

#### 8.6.1 按客户所属销售发送

系统按客户当前归属销售或服务人员对应的企微账号发送。

业务规则：

1. 客户无归属销售时，不进入发送队列或进入异常待处理。
2. 归属销售企微未连接时，该客户不可发送。
3. 当前登录账号必须有权限使用对应发送关系。

#### 8.6.2 指定企微账号发送

用户可以从当前登录账号已授权的企微账号中多选发送账号。

业务规则：

1. 只展示当前登录账号已授权企微账号。
2. 支持多选。
3. 不允许选择无权限企微账号。
4. 后端提交时必须再次校验账号权限，不能只依赖前端过滤。
5. 指定多个企微账号时，客户分配规则需要后端明确，建议按客户归属关系优先；无法匹配时按任务配置策略分配。

## 9. 立即发送与定时发送

### 9.1 立即发送

选择“立即发送”时：

1. 不展示定时发送时间。
2. 用户点击保存任务后，系统立即创建任务并触发发送。
3. 任务状态进入发送中。
4. 发送完成后进入已完成、部分成功或发送失败。

由于立即发送会真实触达客户，前端保存按钮建议使用明确文案，例如“保存并立即发送”。

### 9.2 定时发送

选择“定时发送”时：

1. 展示定时发送时间。
2. 定时发送时间必填。
3. 时间必须晚于当前时间。
4. 保存后任务进入待发送。
5. 到达发送时间后任务进入发送中。

## 10. 发送执行规则

任务进入发送中后，后端按以下步骤执行：

1. 读取任务配置。
2. 根据客户选择模式计算候选客户。
3. 根据标签、状态、阶段等条件筛选客户。
4. 应用排除标签。
5. 做可触达校验。
6. 做企微账号发送权限校验。
7. 生成发送明细。
8. 调用消息通道发送。
9. 写入每个客户的发送结果。
10. 汇总任务状态。

发送结果：

- 成功
- 失败
- 未发送
- 已取消
- 不可触达

任务状态汇总：

- 全部成功：已完成
- 部分成功部分失败：部分成功
- 全部失败：发送失败
- 发送过程中暂停：已暂停
- 发送过程中取消：已取消

## 11. 数据模型建议

### 11.1 群发任务表 `mass_message_task`

```sql
CREATE TABLE mass_message_task (
  id varchar(64) PRIMARY KEY,
  name varchar(128) NOT NULL,
  description varchar(512) DEFAULT NULL,
  business_role varchar(32) NOT NULL,
  audience_mode varchar(32) NOT NULL,
  audience_conditions json DEFAULT NULL,
  audience_tags json DEFAULT NULL,
  audience_tag_rule varchar(32) DEFAULT NULL,
  exclude_tags json DEFAULT NULL,
  exclude_tag_rule varchar(32) DEFAULT NULL,
  estimated_count int NOT NULL DEFAULT 0,
  reachable_count int NOT NULL DEFAULT 0,
  unreachable_count int NOT NULL DEFAULT 0,
  content text NOT NULL,
  material_refs json DEFAULT NULL,
  send_mode varchar(32) NOT NULL,
  scheduled_at datetime DEFAULT NULL,
  send_account_mode varchar(32) NOT NULL,
  send_account_ids json DEFAULT NULL,
  status varchar(32) NOT NULL,
  creator_id varchar(64) NOT NULL,
  creator_name varchar(64) DEFAULT NULL,
  created_at datetime NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at datetime NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  started_at datetime DEFAULT NULL,
  finished_at datetime DEFAULT NULL,
  canceled_at datetime DEFAULT NULL,
  deleted_at datetime DEFAULT NULL,
  KEY idx_status_schedule (status, scheduled_at),
  KEY idx_creator_status (creator_id, status)
);
```

字段说明：

- `audience_mode`：all_customers、filtered_customers
- `send_mode`：immediate、scheduled
- `send_account_mode`：customer_owner、specified_accounts
- `status`：draft、pending、sending、paused、canceled、completed、failed、partial_success、deleted

### 11.2 群发发送明细表 `mass_message_recipient`

```sql
CREATE TABLE mass_message_recipient (
  id varchar(64) PRIMARY KEY,
  task_id varchar(64) NOT NULL,
  customer_id varchar(64) NOT NULL,
  customer_name_snapshot varchar(64) DEFAULT NULL,
  owner_user_id varchar(64) DEFAULT NULL,
  send_account_id varchar(64) DEFAULT NULL,
  reachable tinyint(1) NOT NULL DEFAULT 1,
  unreachable_reason varchar(512) DEFAULT NULL,
  send_status varchar(32) NOT NULL DEFAULT 'pending',
  fail_reason varchar(512) DEFAULT NULL,
  sent_at datetime DEFAULT NULL,
  created_at datetime NOT NULL DEFAULT CURRENT_TIMESTAMP,
  KEY idx_task_status (task_id, send_status),
  KEY idx_customer (customer_id)
);
```

字段说明：

- `send_status`：pending、success、failed、canceled、unreachable、skipped
- 不可触达客户可进入明细表，便于查看原因；也可单独汇总保存，按后端实现决定。

### 11.3 群发素材关联表 `mass_message_material`

```sql
CREATE TABLE mass_message_material (
  id varchar(64) PRIMARY KEY,
  task_id varchar(64) NOT NULL,
  material_type varchar(32) NOT NULL,
  material_name varchar(128) DEFAULT NULL,
  material_url varchar(1024) DEFAULT NULL,
  resource_id varchar(64) DEFAULT NULL,
  sort_order int NOT NULL DEFAULT 0,
  created_at datetime NOT NULL DEFAULT CURRENT_TIMESTAMP,
  KEY idx_task (task_id)
);
```

### 11.4 操作日志表 `mass_message_operation_log`

```sql
CREATE TABLE mass_message_operation_log (
  id varchar(64) PRIMARY KEY,
  task_id varchar(64) NOT NULL,
  operator_id varchar(64) NOT NULL,
  operator_name varchar(64) DEFAULT NULL,
  operation varchar(32) NOT NULL,
  before_data json DEFAULT NULL,
  after_data json DEFAULT NULL,
  created_at datetime NOT NULL DEFAULT CURRENT_TIMESTAMP,
  KEY idx_task_time (task_id, created_at)
);
```

操作类型包括：

- create
- update
- copy
- delete
- pause
- resume
- cancel
- send_start
- send_finish

## 13. 异常与边界场景

| 场景 | 说明 | 系统处理 |
| --- | --- | --- |
| 预计发送人数为 0 | 筛选后没有可触达客户 | 禁止提交发送，提示调整人群 |
| 全部客户中存在不可触达客户 | 部分客户已删除企微或无权限 | 自动剔除不可触达客户，展示数量和原因 |
| 排除标签和目标标签同时命中 | 同一客户既满足目标又满足排除 | 排除优先，不发送 |
| 定时发送时间早于当前时间 | 用户选择过期时间 | 阻止保存，提示选择未来时间 |
| 指定账号为空 | 选择指定企微账号发送但未选择账号 | 阻止保存 |
| 指定账号无权限 | 前端或接口传入未授权账号 | 后端阻止提交，返回权限错误 |
| 发送账号离线 | 任务执行时企微账号未连接 | 对应客户发送失败或不可触达，记录原因 |
| 发送中暂停 | 任务正在批量发送 | 已发送保留结果，未发送停止进入队列 |
| 发送中取消 | 任务正在批量发送 | 已发送保留结果，未发送标记已取消 |
| 已发送任务删除 | 任务已发送中、已完成、部分成功或失败 | 禁止删除 |
| 素材类型不支持 | 通道不支持视频、文件等类型 | 阻止提交或发送失败并记录原因 |
| 消息接口失败 | 企微发送接口报错 | 记录失败原因，任务汇总为失败或部分成功 |
| 客户重复命中 | 多个筛选条件重复命中同一客户 | 发送队列按客户去重，同一任务同一客户只发一次 |
| 重复点击保存 | 用户连续提交 | 前端禁用按钮，后端幂等处理 |
| 任务执行中被编辑 | 发送中任务不允许编辑 | 阻止编辑 |
| 客户归属变化 | 定时任务创建后客户归属销售变化 | 发送时按执行时最新归属和权限校验 |

## 14. 非功能需求

1. 页面风格保持后台系统风格，信息密度高，操作清晰。
2. 列表支持分页、筛选和横向滚动。
3. 任务创建表单需支持较长内容输入，避免按钮和字段挤压。
4. 群发任务提交、暂停、取消、删除等关键操作需防重复点击。
5. 真实触达客户前需有明确操作反馈。
6. 后端所有发送相关操作必须做权限校验。
7. 发送任务应支持异步执行，前端不阻塞等待全部发送完成。
8. 发送失败需保留错误原因。
9. 删除、暂停、取消、发送等操作需记录操作日志。
10. 群发内容和素材需保留发送时快照，后续编辑素材或内容不影响历史记录。

## 15. 验收标准

### 15.1 任务列表

1. 用户可以查看群发任务列表和任务统计。
2. 用户可以按名称、状态、业务角色筛选任务。
3. 列表正确展示目标人群、预计发送人数、发送时间、发送账号和状态。
4. 不同状态任务展示对应可用操作。

### 15.2 创建与编辑

1. 用户可以创建群发任务。
2. 用户可以编辑草稿、待发送、已暂停任务。
3. 发送中、已取消、已完成、发送失败、部分成功任务不可编辑。
4. 必填项为空时不能保存。
5. 定时发送必须选择未来时间。
6. 立即发送点击保存后直接进入发送中。

### 15.3 人群选择

1. 选择全部客户时，不展示标签和状态筛选。
2. 选择筛选客户时，展示托管状态、所处阶段、标签和排除标签。
3. 标签选择使用统一标签选择弹窗。
4. 排除标签优先于目标标签。
5. 最终发送对象只包含可触达客户。

### 15.4 发送账号

1. 用户可以选择按客户所属销售发送。
2. 用户可以选择指定企微账号发送。
3. 指定企微账号只展示当前登录账号已授权账号。
4. 指定企微账号支持多选。
5. 后端会拦截未授权企微账号。

### 15.5 任务控制

1. 草稿、待发送任务可以删除。
2. 已经产生发送行为的任务不可删除。
3. 待发送、发送中任务可以暂停。
4. 草稿、待发送、发送中、已暂停任务可以取消。
5. 发送中取消后，已发送记录保留，未发送客户标记为已取消。

### 15.6 发送记录

1. 任务执行后生成客户发送明细。
2. 每个客户展示发送状态和失败原因。
3. 任务可汇总为已完成、部分成功、发送失败。
4. 发送记录不可删除。
5. 操作日志可追溯创建、编辑、发送、暂停、取消、删除等动作。

## 16. 待确认问题

以下问题不影响一期主流程，但建议研发排期前确认：

1. “可触达客户”的风险禁止触达标签清单是否固定，例如删除企微风险、投诉风险、不适合 AI 继续沟通。
2. 指定多个企微账号发送时，客户与发送账号的分配策略是否按客户归属优先。
3. 立即发送是否需要二次确认弹窗，避免误触达。
4. 单任务素材数量、单素材大小、视频和文件格式限制由哪个通道标准决定。
5. 是否需要群发频控，例如同一客户一天最多接收几次群发。
6. 普通销售 / 班主任是否有创建群发任务权限，还是只允许主管和运营创建。
